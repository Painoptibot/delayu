### Блок C. Демо для эксперта (сквозной сценарий)

**Сценарий «5 минут» (записать screencast):**

1. Регистрация **входящего обращения** → ИИ классификация → подтверждение.  
2. Загрузка **скана заявления** → OCR → предзаполнение полей.  
3. Проверка **полноты пакета** → список недостающих.  
4. **Семантический поиск** по тексту из обращения.  
5. **Черновик ответа** → правка → печать/PDF.  
6. **Журнал ИИ** — все шаги видны.

## Чек-лист «не забыть перед отправкой заявления»

- [ ] В заявлении класс **09.01** + ОКПД2 **62.01.29.000**
- [ ] Текст обоснования ИИ **совпадает** с функциями на стенде
- [ ] URL стенда и документации — **рабочие**
- [ ] HITL: ни одно решение ИИ не применяется без кнопки пользователя
- [ ] Журнал `AiRequestLog` пишется на каждый вызов
- [ ] Сcreencast или PDF сценария приложен к ответам на замечания
